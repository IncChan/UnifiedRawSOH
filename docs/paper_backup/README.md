# Paper-Backup 文档索引

Paper-Backup 是与 Paper-v1、Paper-v2 并列的 terminal raw CC/CV SOH estimation 论文路线。

- `PAPER_STORY.md`：已确认的论文问题、方法边界、E1–E3 证据链和非主张内容；
- `E1_E3_DEVELOPMENT_PROMPT.md`：可直接交给下一位开发助理的 E1–E3 实现 prompt。
- `DATA_AND_IMPLEMENTATION_AUDIT.md`：canonical terminal/full source、split 和实现边界审计；
- `DEVELOPMENT_STATUS.md`：逐组件实现、测试、可运行性和 blocker 状态。

当前只授权开发 E1–E3。E4 robustness、window-position search、cross-domain transfer 和正式长时间 GPU 训练均不在当前范围内。
